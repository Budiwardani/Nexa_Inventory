# Nexa_Inventory

Nexa-MFG Enterprise Platform (Laravel + React + PostgreSQL)

An Enterprise Manufacturing Platform (MRP + MES Lite) designed for Enterprise and SaaS deployment.

## Tech Stack
- **Backend**: Laravel 12, PostgreSQL 17+, Modular Monolith Architecture
- **Frontend**: React 19, Vite, TailwindCSS v4, Shadcn UI, TanStack Query

## Status
Core modules (Authentication, Users, Branches, Roles, Permissions) and initial frontend foundation (Layouts, API integration) have been initialized.
